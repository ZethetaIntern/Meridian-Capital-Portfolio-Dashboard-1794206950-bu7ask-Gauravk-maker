# Testing guide

Run all tests with `npm run test`; run coverage with `npm run test:coverage`. Vitest uses jsdom and Testing Library. Test suites cover:

- Widget catalogue count, key widget rendering and unknown widget fallback.
- Registry registration/lookup and duplicate handling.
- Layout serialization, schema validation and invalid JSON.
- Typed event bus subscription and cleanup.
- Historical/parametric VaR, expected shortfall, drawdown, Sharpe, Pearson correlation and Brinson decomposition.
- Mock price tick immutability and stream lifecycle.

Coverage is generated by V8 into `coverage/`. The assignment's >70% threshold must be confirmed from the generated report after dependencies are installed; this repository does not claim a measured coverage percentage before that run.
